## 🌟 Features

✅ **Real-time AI enemy behavior with unpredictable patterns**  
✅ **Multiple endings based on player choices**  
✅ **Advanced lighting and shadow system creating an eerie atmosphere**  
✅ **Customizable difficulty levels and horror intensity**  
✅ **Interactive environment with objects that can be used for survival**  
✅ **Dynamic sound effects and spatial audio for an immersive experience**  
✅ **Stealth mechanics allowing players to hide and evade enemies**  
✅ **Procedural scare system ensuring each playthrough feels unique**

## ⚙️ Installation

### **🔧 Prerequisites**

- Install **Unity Hub**, **Unity 2021+**, **Visual Studio**
- Clone this repository:

```sh
git clone https://github.com/maigiaminh/3D-Horror-Game.git
cd 3D-Horror-Game
```

### **💻 Run the Application**

1. Open the project in **Unity Hub**
2. Select the correct Unity version and open the project
3. Click **Play** to test the game

## 🛠 Technologies

- **Game Engine:** Unity
- **Programming Language:** C#
- **AI System:** FSM-based enemy behavior
- **Graphics:** Blender models & Unity Post-Processing
- **Audio:** FMOD for dynamic sound effects
